# CashFlow

HTW WebTech - CashFlow


Themenbeschreibung

Die CashFlow-App ist eine einfache Webanwendung zur Erfassung von Ausgaben.
Sie unterstützt Nutzer dabei, Auszahlungen zu speichern und einen Überblick über ihre täglichen und monatlichen Ausgaben zu erhalten.


Funktionsidee

-Nutzer können Auszahlungen speichern

-Zu jeder Auszahlung werden folgende Daten erfasst:
    Betrag 
    Datum
    Zahlungsart (z. B. Bar, Karte)
    Verwendungszweck (z. B. Lebensmittel, Kleidung, Fahrtkosten)
    optionale Notiz

-Die Anwendung berechnet automatisch:
    die Gesamtausgaben pro Tag
    die Gesamtausgaben pro Monat

-Zusätzlich können Ausgaben nach Kategorie ausgewertet werden

-Filterfunktionen ermöglichen eine gezielte Ansicht der Ausgaben
